# 🏐 SportSync — Plataforma Web Progresiva para Gestión de Vóley

> **Progressive Web App (PWA)** diseñada para optimizar la gestión operativa de infraestructura (canchas), la agenda de partidos oficiales de la Federación Cordobesa de Voleibol (FCV) y el control automatizado de convocatorias/asistencia deportiva.

**Cliente:** Club Empleados Banco Nación Córdoba (CEBNAC)  
**Disciplina:** Vóleibol Femenino  
**Metodología de Trabajo:** Scrumban (Sprints de 2 semanas)

---

## Alcance y Objetivos del Sistema

SportSync digitaliza y centraliza la operativa deportiva resolviendo tres problemáticas críticas:
* **Gestión de Infraestructura en Tiempo Real:** Control visual del estado de las 5 canchas del predio (3 cubiertas y 2 descubiertas), eliminando solapamientos de turnos y permitiendo inhabilitación por contingencia climática.
* **Fixture y Logística de Partidos FCV:** Calendario interactivo multi-vista con vinculación a reservas locales y enlaces de geolocalización GPS para sedes visitantes.
* **Control de Asistencia y Convocatorias:** Citación digital de planteles con regla de bloqueo automático a menos de 24 horas del encuentro y dashboard de confirmaciones en vivo para el cuerpo técnico.
* **Alertas Móviles Inmediatas:** Notificaciones Web Push enviadas a los dispositivos de jugadores y cuerpo técnico ante suspensiones por clima o nuevas convocatorias.
